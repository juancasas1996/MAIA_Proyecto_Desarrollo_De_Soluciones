# Experimentos

Esta carpeta agrupa los experimentos de modelado de la Entrega 2. La regla del
repositorio es mantener una carpeta por integrante y dejar los archivos
compartidos en la raiz de `Experimentos/`.

## Compartido

- `config.py`: configura la conexion de MLflow.
- `config.yaml`: guarda host y puerto del servidor MLflow.
- `subject_split_seed42.json`: particion oficial por sujeto. No se regenera.

## Por integrante

- `Sebastian/`: notebooks de particion, extraccion de caracteristicas,
  modelado Ridge y empaquetamiento del modelo.
- `Diego/`: notebooks de exploracion con Pz-Oz, SEF95 y Gradient Boosting.
- `Isabella/`: scripts de procesamiento EEG, Ridge y Random Forest.
- `JuanCamilo/`: experimento Random Forest, datos derivados y resultados.
